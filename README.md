# 1899 Barcelona Vision — Interactives

Автономный набор быстрых интерактивов для русскоязычных болельщиков «Барселоны». Регистрация и база данных не нужны: пользователь выполняет одно действие и скачивает брендированную PNG-карточку.

## Страницы

- `/sostav` — стартовый состав из 11 игроков;
- `/prognoz` — исход и точный счёт;
- `/rating` — рейтинг 16 игроков после матча;
- `/fantasy` — Fantasy-пятёрка с бюджетом и капитаном;
- `/transfer-vhod` — главная трансферная цель;
- `/transfer-vyhod` — игрок на выход;
- `/transfer-verdict` — вердикт по конкретному трансферу;
- `/la-masia` — выбор таланта академии.

## Запуск

```bash
pnpm install
pnpm dev
```

Локальный адрес по умолчанию: `http://localhost:3000/sostav`.

## Брендинг

Скопируйте `.env.example` в `.env.local` и укажите подтверждённые значения:

```env
NEXT_PUBLIC_BRAND_NAME=1899 Barcelona Vision
NEXT_PUBLIC_TELEGRAM_HANDLE=@your_channel
```

Telegram-адрес автоматически появится на скачиваемых карточках. Матч и время первой версии находятся в `lib/config.ts`, состав и варианты — в `lib/data.ts`.
